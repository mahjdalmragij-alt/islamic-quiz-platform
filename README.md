# منصة منافسات الدراسات الإسلامية - متوسطة العفج

منصة تفاعلية تعليمية وتنافسية شاملة لمقرر الدراسات الإسلامية للمرحلة المتوسطة (الصف الأول، الثاني، والثالث متوسط) للفصل الدراسي الأول وفق المنهج السعودي الحديث 1448هـ.

## المميزات
- **بنك أسئلة شامل**: أكثر من 600 سؤال تفاعلي مقسمة على الصفوف الدراسية والوحدات والدروس.
- **5 أطوار مسابقات ذكية**:
  - 🏆 مسابقة من سيربح المليون (تحدي المليون الإسلامي مع وسائل مساعدة وعداد تنازلي).
  - 👥 دوري الفرسان (منافسة الفرق بين المجموعات).
  - ⚔️ صراع الأذكياء (مبارزة ثنائية رأس برأس).
  - 🎡 عجلة الحظ والتحدي (اختيار عشوائي للطلاب والأسئلة).
  - ⚡ التحدي السريع (اختبار سريع ومحدد بوقت).
- **إدارة الطلاب والفصول**:
  - دعم كامل لجميع فصول أول متوسط، ثاني متوسط، وثالث متوسط.
  - إضافة الطلاب فردياً أو لصق جماعي من نظام نور.
  - تصدير واستيراد النسخ الاحتياطية لبيانات الطلاب بضغطة زر (JSON).
- **تصميم تفاعلي وجذاب**: أصوات حماسية، بطاقات شرف، وشهادات للأبطال.
